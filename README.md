# 🌍 TripTrace — Smart Travel Companion App

> Live Website: https://triptrace-sanjay.netlify.app

## About
TripTrace is a professional travel logging web app built for Smart India Hackathon 2025 (PS: SIH25082).

## Features
- 🔐 Login & Signup with Google
- 📍 World Places Search
- 🗺️ Interactive Maps
- 🌤️ Live Weather
- 📸 Photo Upload
- 💸 Expense Tracker
- 📋 Trip History

## Tech Stack
- HTML, CSS, JavaScript
- Firebase (Auth + Firestore)
- Leaflet.js Maps
- OpenWeatherMap API
- Cloudinary (Photos)
- Netlify (Hosting)
